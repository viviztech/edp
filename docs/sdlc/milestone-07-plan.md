# Milestone 7 plan — mentoring and business support

M01 is the first Phase 7 slice. It delivers mentor administration, assignment, sessions, privacy-controlled notes, goals, action items, follow-up reminders, participant feedback and operational monitoring as one vertical slice. B01 business plans and B02 post-training tracking remain subsequent work.

Acceptance requires migration upgrade/downgrade and drift checks, focused PostgreSQL journey tests, permission and privacy negatives, generated API contracts, English/Tamil staff and participant web flows, BFF allowlist tests, web lint/type/test/build, authenticated browser checks and audit evidence. Native mentor mobile access is deferred under ADR 0004.
