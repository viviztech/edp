# Entrepreneur business tools — local implementation

2026-10-24. Implements the four authorized slices in [the plan](business-tools-plan.md), with the [API contract](../api/business-tools.md) and [web acceptance plan](business-tools-web-plan.md). Full API regression and final schema verification are reconciled in the project closure report; this document does not waive remote CI or release gates.

Digital cards and catalogues have English/Tamil private editing, previews and separate versioned publication/revocation. Existing business-profile interest does not publish anything. Saving shared content revokes its share. Anonymous views expose only the deliberately public fields, use no-store requests and remove revoked content on the next request. Card and quotation artifacts are escaped, audited, authorized printable HTML attachments with restrictive CSP.

Quotations support manual and owned current catalogue lines, exact decimal quantities/prices, per-line HALF_UP cent rounding, discounts and server totals. Issue rechecks references, freezes the business/customer/line snapshot and prohibits edits to issued evidence. PostgreSQL enforces scope/version/immutability and deferred line/totals constraints. Follow-up revision q3 explicitly closes the nullable catalogue ID/version pair check.

The entrepreneur contact/follow-up module stays private and separate from marketing CRM. It provides bounded status/name/contact filters, pagination, UTC due times, terminal completion/cancellation and safe version/action history. All private reads, writes, retries, exact-resource refreshes and artifacts reauthorize the current owner/enrollment. Immutable request UUID/digests prevent duplicates; stale and interrupted commands preserve input. Current-resource detail recovery works even after the record leaves a page/filter. Explicit use-saved/discard controls avoid trapping edits after a concurrent archive or task settlement.
