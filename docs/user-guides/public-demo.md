# Presenting the public website

Open the website in English or Tamil and choose **Try the demo**. No sign-in or password is needed.

1. Choose **Start the demo** and create the supplied sample profile.
2. Review the fictional intake and sample application. Edit sample answers, then choose **Save demo draft**.
3. Accept the demo declaration and submit. A reference beginning with `DEMO-` appears.
4. Open the demo space. Explore the Overview, Learning, Mentoring and Application sections.
5. Complete a practice lesson and save a sample mentoring slot. Return to Overview to see the updated state.
6. Choose **Restart demo** to return to the beginning. Refreshing or closing the tab also clears progress.

The sample program, intake dates, profile and appointment slots are fictional. The demo sends no email and creates no real admission, enrollment, application or appointment. Use sample information during the presentation.

The **Idea planner** is a separate working resource. Answer its six questions and download a UTF-8 text file, in English or Tamil. Answers stay in the current tab until downloaded or cleared. The planner does not automatically save them.

Existing real accounts use **Sign in** in the footer. Registration, verification and password-reset actions for real accounts are closed until transactional email and the approved program intake are ready.
