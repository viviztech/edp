# Trainer learning delivery

Open **Admin > Learning** after an administrator grants the Trainer role and assigns your account to a training center or cohort. The page lists only published courses for covered cohorts, their ordered modules and lessons, private material labels, and learner course progress.

Select **Open material** to request a short-lived private download. The link is tied to your current session and assignment. If an assignment is revoked or expires, refresh the page; access is removed immediately. Report an unavailable file to the program administrator with the course and material label, never with a copied access URL.

Trainers cannot change course structure, publish courses, assign courses or edit learner progress. Program Managers and Directors create staff assignments from **Admin > Programs > Center and cohort staff assignments** using the trainer's existing organization account email.

## Review quiz results

The learner section shows each quiz's attempt count, best percentage and pass state for participants in your assigned cohort. Results are read-only and do not include the answer key or selected answers. A revoked staff assignment removes these results on the next request.

## Grade assignments

The learner section lists assignment response text and **Immutable submitted evidence** for participants in your assigned cohort. A file receipt identifies the frozen version and digest. **Download verified file** appears only for usable frozen evidence; pending scans, expiry or withdrawn access prevent delivery. **Refresh saved files** repeats current access checks. A receipt or earlier link does not preserve access after the trainer assignment or permission ends.

For an ungraded revision, enter points within the displayed maximum and useful feedback, then save the grade. The pass state is calculated from the assignment threshold. A saved grade is permanent; verify the learner, revision, response and submitted evidence before saving. Revoked or expired staff scope removes grading and file access immediately. Trainers cannot change or replace submitted learner files.

## Certificate eligibility

Trainer delivery shows the derived lesson, quiz and assignment evidence used for certificate eligibility. Trainers can help learners complete missing evidence but cannot publish templates, issue certificates or revoke them. Escalate an eligible learner to an authorized Program Director; never treat the browser display as permission to create external certificates.
